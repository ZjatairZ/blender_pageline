# 🖥️ 3D Interactive Portfolio – Web Visualization using Three.js & Blender

## 📌 Project Overview

This project showcases an **interactive 3D work-station environment**, modeled in **Blender** and rendered on the web with **Three.js**.  
The purpose is to demonstrate the ability to integrate **3D modeling**, **WebGL rendering**, and **modern web UI** into a single portfolio-style web project.

Users can:

- 🌀 Rotate, zoom, and move around the 3D model  
- 💡 Switch between **light mode** and **dark mode**, dynamically changing lighting  
- 📦 Load a complete `.gltf` / `.glb` model exported from Blender  
- 📁 Organize textures, materials, and assets in a clean web folder structure  

---

## 🎯 Features

- **Three.js** scene with perspective camera  
- **OrbitControls** for intuitive interaction    
- **Modular structure** (HTML + CSS + JS separated)  
- Support for **uploaded 3D models** including geometry, materials, and textures  

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| **Three.js** | Renders the 3D model in the browser |
| **Blender** | Modeling and export of .gltf/.glb |
| **JavaScript (ES6)** | Logic, event handling, model loading |
| **OrbitControls** | 3D camera manipulation |
| **GLTFLoader** | Loads .gltf / .glb models into Three.js |
